# Proposal: Light Mode Support for TecniDesk

## Goal
Implement a light theme toggle across the TecniDesk frontend (admin panel and public pages) to make the interface less dark-monolithic and more professional, while adhering strictly to the existing amber/gold aesthetic palette.

## Motivation
The application currently only supports a dark mode, which can look generic or be hard to read in bright environments. Introducing a high-quality light mode increases usability while keeping the brand colors cohesive.

## Capabilities
- `theme`: Theme selection context, persistent preferences, and theme toggle buttons.
